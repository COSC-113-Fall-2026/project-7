# Project 7: Student Scholarship and Financial Assistance Management System

## Instructions for this Assignment

1. All Java files you create must go into the `src/project7` folder. Keep the `README.md` file in the project root.

2. Some classes and files have been provided as starter code, while others have intentionally been left out. Using what you have learned in class, complete the project by adding the missing classes and implementing the required relationships and functionality.

3. The starter code is intentionally incomplete. The provided classes are only part of the design; determine what additional classes, attributes, methods, and relationships are needed to create a complete application.

4. Apply the object-oriented programming concepts covered in class, including encapsulation, constructors, inheritance, method overloading, method overriding, polymorphism, and arrays of objects.

5. Do not use AI coding tools to complete this assignment. If you have difficulty, reach out to your Teaching Assistant or Professor for help.

## Project overview

Develop a Java application that implements the requirements for **Student Scholarship and Financial Assistance Management System**.

## Suggested data files

students.txt, scholarships.txt, applications.txt, awards.txt, users.txt

The completed application must load records automatically, store them in arrays of objects, and save additions or updates between executions.

## Shared requirements

- Console application is mandatory; GUI is optional bonus only.
- Demonstrate encapsulation, constructors, inheritance, overloading, overriding, polymorphism, and arrays of objects.
- Use multiple file-based data files with meaningful initial records.
- Load records automatically at startup and persist additions and updates.
- Handle missing files, invalid records, duplicate IDs, read errors, and write errors.
- Full business logic, persistence, authentication, validation, and menus remain to be implemented
